# Nuit Lumière — витрина из 30 ароматов

Многостраничный премиальный storefront на React, TypeScript, React Router и Vite. Отдельные URL: главная `/`, коллекция `/collection`, каждый аромат `/aroma/:id`, Maison `/maison`, доставка `/delivery`, контакты `/contact` и конфиденциальность `/privacy`. Прямое открытие маршрутов поддерживается SPA fallback.

В каталоге — 30 вымышленных композиций с ценами в евро и оригинальными SVG-флаконами: шесть авторских силуэтов стекла, металлические крышки и отдельная палитра для каждого аромата; узнаваемые бренды и чужие логотипы не копируются. На главном экране — пользовательский ролик 5,04 секунды, 1280×720, H.264 с сохранённой стерео-AAC музыкальной дорожкой. Автовоспроизведение начинается без звука по правилам браузеров; кнопка «Включить музыку» включает звук после касания.

## Запуск

```bash
npm ci
npm run dev
```

Проверки и production-сборка:

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```

## Публикация через Cloudflare Wrangler

Проект содержит `wrangler.jsonc`: он публикует собранный многостраничный SPA из `dist/` и возвращает `index.html` для клиентской маршрутизации. После входа в Cloudflare выполните безопасную проверку, затем отдельно запустите реальную публикацию:

```bash
npm run deploy:dry-run
npm run deploy
```

`deploy:dry-run` не публикует сайт; `deploy` загружает его в Cloudflare Workers Static Assets. При необходимости выполните `npx wrangler login` заранее.

## Данные и визуалы

Каталог и демонстрационные цены находятся в `src/data/products.ts`. Валюта форматируется как EUR в `src/lib/money.ts`. Иллюстрации создаются компонентом `src/components/BottleVisual.tsx`; предметная фотография коллекции — `public/perfume-atelier.jpg`.

## Перед коммерческой публикацией

Названия и цены — демонстрационный макет, а не подтверждённое коммерческое предложение. Перед продажей замените данные реальным ассортиментом и ценами. Корзина хранится в `localStorage`, checkout показывает только локальное демо-подтверждение: персональные данные не отправляются и не сохраняются, заказ и оплата не выполняются. Для реального запуска подключите защищённый backend заказов и платёжный провайдер, укажите доставку, контакты, политику конфиденциальности и условия продажи/возврата.
